# 행복-가게 디자인 시스템: 하루 한 알, 행복 비타민

작성일: 2026-11-12
대상: 행복-가게(운세·위로·글귀·음악·꽃말·레시피·여행)와 비타민 슬롯을 **사랑하기**로 받는 흐름
시안: Breaktime 행복-가게 디자인 컨셉 캔버스(https://claude.ai/artifact/LHQmndk66D7A5VzA21Teha, 비공개)

## 1. 컨셉

행복-가게는 마음을 챙긴 만큼 모인 **사랑하기**로 오늘의 작은 위로를 꺼내 가는 곳입니다.

- **비유:** 앱에 이미 있는 비타민 알약 사진 8장(`assets/images/pill/`)을 그대로 씁니다. 가게의 8칸을 8가지 비타민으로 봅니다.
- **브랜드 연결:** 앱의 세 가지 색을 이어 씁니다.
  - 앱 테마의 복숭아빛 코랄(`#FF9E80`)
  - 음표 로고의 자주색
  - 알약 사진의 크림색 바탕

### 원칙 3가지

| 원칙 | 뜻 | 화면에서 |
| --- | --- | --- |
| 따뜻하게 | 상점이 아니라 쉼터처럼 | "구매·결제" 대신 "받기·꺼내기·늘리기"를 씁니다. |
| 투명하게 | 언제, 몇 개가 빠지는지 늘 보입니다 | 확인 창에 "지금 12 → 받은 뒤 11"을 보여 줍니다. |
| 안심되게 | 결과가 나온 뒤에만 빠집니다 | 확인 창과 실패 화면에 "빠지지 않았어요"를 씁니다. 1단계에서 만든 결과 후 차감과 맞습니다. |

## 3. 글자

앱에 이미 있는 두 글꼴만 씁니다(`pubspec.yaml`의 `customFontFamily`).

| 단계 | 크기/줄 높이 | 글꼴 | 쓰는 곳 |
| --- | --- | --- | --- |
| Display | 28/36 | 티머니 둥근바람 800 | 화면 제목 |
| Sheet title | 22/30 | 티머니 둥근바람 800 | 아래에서 올라오는 창 제목 |

## 4. 모양과 간격

- **모서리:**
  - 칩, 가격표: 999
  - 버튼, 입력칸: 14
  - 카드: 20
  - 아래에서 올라오는 창(위쪽 모서리만): 28
- **간격:** 4의 배수만 씁니다(4, 8, 12, 16, 20, 24, 32).
- **누르는 곳:** 48dp 이상입니다. 지금 가게에는 약 20dp인 버튼이 있습니다.
- **그림자:** 아주 옅게 둡니다. 카드는 테두리 1px로 나눕니다.

| 받기 확인 창 | 아래에서 올라오는 창 | 내용: 무엇을 받는지, "지금 → 받은 뒤" 숫자, "도착한 뒤에 빠져요", 버튼 [받기]·[다음에]. 기획서 2-2입니다. |
| 부족 안내 창 | 아래에서 올라오는 창 | "N개만 더 모으면 돼요"와 얻는 방법 3가지(행복-미션 100%, 행복-함 쓰기, 매일 서랍 열기)를 보여 줍니다. 각각 하루 1번 +1이고, 오늘 받았는지도 표시합니다. 기획서 2-3입니다. |
| 상태 표시 | 준비 중 / 도착 / 문제 | 준비 중: "아직 빠지지 않았어요". 문제: "사랑하기는 그대로예요" + [다시 시도 · 무료]. 기획서 2-5입니다. |

## 7. 화면 흐름(시안 5장)

1. **행복-가게 홈**: 상단바에 잔액 칩을 둡니다. 그 아래에 "오늘 모은 사랑하기 2/3"과 8칸 카드가 있습니다.
2. **받기 전 확인**: 카드를 누르면 확인 창이 열리고, 받으면 결과 화면으로 갑니다.
3. **결과·상태**: 결과는 편지 카드로 보여 주고, 아래쪽 알림으로 차감을 알립니다. 준비 중·문제 상태도 함께 정리했습니다.
4. **부족할 때**: 확인 창 대신 부족 안내 창이 열립니다.
5. **비타민 슬롯 늘리기**: 사랑하기 5개로 늘리고, 최대 20개입니다. 채우기·비우기는 무료입니다.

## 8. 코드에 옮기는 방법(개발팀 참고)

1. `lib/core/theme/`에 `ShopTokens extends ThemeExtension`을 만듭니다(밝은·어두운 두 벌). `AppTheme.lightTheme/darkTheme`의 `extensions`에 더합니다.
2. 공통 위젯을 만듭니다(`lib/happiness_shop_2/common/widgets/`).
   - `LoveBalanceChip`, `LovePriceTag`, `LoveButton`
   - `SpendConfirmSheet`, `NotEnoughSheet`, `ShopStatusView`
3. 8개 탭의 직접 색 지정(`Colors.purple` 등)을 토큰으로 바꿉니다.
4. 가게 헤더를 없애고, 잔액 칩을 상단바로 옮깁니다(2-4).
5. 화면 문구를 6장의 표대로 바꿉니다(2-1).
6. 사랑하기 차감은 1단계에서 만든 `ShopChargeService`를 그대로 씁니다. 확인 창의 "받은 뒤" 숫자는 화면에서 계산만 하고, 실제로 빼는 것은 결과가 나온 뒤입니다.

## 9. 사람이 정할 일

| 번호 | 정할 일 | 디자인팀 의견 |
| --- | --- | --- |
| D-1 | 코랄 상단바 글자를 흰색에서 Cocoa로 바꾸는 것을 **앱 전체**에 할지, 가게에만 할지 | 앱 전체를 권합니다. 대비 문제가 앱 전체에 있습니다. |
| D-2 | 어두운 화면을 따뜻한 갈색으로 바꾸는 것을 앱 전체에 할지 | 가게부터 적용하고, 반응을 본 뒤 넓히기를 권합니다. |
| D-3 | 가격(모두 1개, 슬롯 5개)과 하루에 얻는 양(최대 3개)이 맞는지 | 자료에 사용 통계가 없습니다. 3-4(사용 통계)를 먼저 하기를 권합니다. |
| D-4 | 사랑하기를 쓸 때마다 확인 창을 띄울지, "다시 묻지 않기"를 둘지 | 처음 3번만 묻고, 그 뒤에는 버튼 아래 글로 알리기를 권합니다. |
